🔒 How is my data secured?

CablePod uses End-to-End Encryption (E2EE). Before your data leaves this device, it is encrypted using a 256-bit AES-GCM key derived directly from your 8-word passphrase.

Your passphrase is never sent over the internet. Instead, it is cryptographically hashed into a random identifier so the server knows where to save the file. Because of this, whether you use Cloudflare, GitHub, or a Custom Server, the host only sees an unreadable blob of data and can never access your podcasts.
